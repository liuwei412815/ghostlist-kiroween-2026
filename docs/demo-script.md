# GhostList demo plan

Target duration: about 100 seconds. Record the actual application. Do not use
this script as evidence that a video has already been recorded.

## 0:00-0:12 - The idea

Show the full board with the three clearly labelled sample tasks.

"This is GhostList. It's a small task app for the little things that keep
haunting you. Give them a home, focus on one, and let it go."

## 0:12-0:35 - Create something real

Click Summon a task. Add "Finish the first draft", with the note "Write the
opening paragraph", a medium priority and a 15-minute estimate. Save.

"A task can be as small as one next step. I can add a priority, a rough time
estimate, and a date if that helps."

## 0:35-0:55 - Focus

Click Focus on this on the new task. Select 5 minutes. Start the timer, let it
run briefly, pause, and resume.

"I don't need to tackle the whole board. I can pick one ghost and give it a
little quiet time. The timer follows elapsed time, even when I switch tabs."

## 0:55-1:15 - Finish and restore

Click Let it go. Show the animation, then click At peace. Restore the task if
useful to demonstrate a change of plans.

"When I'm done, the ghost disappears from the active board. It isn't lost:
finished tasks live here, and I can bring one back."

## 1:15-1:30 - Data and accessibility

Show search, a smaller viewport, and the export control.

"The app keeps tasks in this browser and supports JSON backups. It works on a
small screen and respects reduced-motion settings."

## 1:30-1:40 - Close

Return to the board.

"That's GhostList. One less ghost. A little more headspace."

## Production notes

- Use only actual footage of the current build.
- If discussing Kiro, add a short factual explanation after a real Kiro session.
- Do not show private tasks, account menus, tokens or unrelated browser tabs.
- No copyrighted music or third-party imagery is needed.
